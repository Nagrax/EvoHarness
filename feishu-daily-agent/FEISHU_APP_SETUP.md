# 飞书自建应用配置指南（从零开始）

全程在飞书开放平台操作：https://open.feishu.cn ，用企业账号登录。

## 1. 创建企业自建应用

1. 进入「开发者后台」→ 点击「创建企业自建应用」。
2. 填写应用名称（如「我的日报助手」）、描述，创建后进入应用详情页。
3. 左侧「应用功能」→「机器人」→ 启用机器人能力。

## 2. 申请权限

左侧「权限管理」，开通以下权限（推荐组合，覆盖读取与发送）：

| 权限标识 | 权限名称 | 用途 |
|---|---|---|
| `im:message` | 获取与发送单聊、群组消息 | 读取单聊消息 + 机器人发消息 |
| `im:message.group_msg` | 获取群组中所有消息 | 读取群聊消息（机器人需在群内） |

最小权限替代方案（权限更收敛时使用）：
`im:message:readonly` + `im:message.group_msg` + `im:message:send_as_bot`。

> 群聊消息的前提：把机器人添加进对应群组（群设置 → 群机器人 → 添加机器人）。

## 3. 配置事件与回调（长连接模式，无需公网 IP）

1. 先在服务器上把程序跑起来（见 README，`python main.py` 或 docker compose up），
   长连接需要程序在线才能完成保存。
2. 开放平台左侧「事件与回调」→「事件配置」：
   - 订阅方式选择「使用长连接接收事件」并保存；
   - 添加事件：搜索并勾选 **`im.message.receive_v1`（接收消息）**。
3. 同页面「回调」→ 添加回调：勾选 **`card.action.trigger`（卡片回传交互）**，
   用于日报里批准/驳回按钮。
4. 加密策略保持默认即可，长连接模式由 SDK 处理鉴权，无需 Encrypt Key。

## 4. 发布并设置可用范围

1. 左侧「应用发布」→「版本管理与发布」→「创建版本」。
2. 「可用范围」编辑为包含你自己（以及需要机器人服务的同事/群）。
3. 提交发布，等待企业管理员审批通过。权限变更后都需要重新发布版本生效。

## 5. 获取凭证并填写 .env

1. 「凭证与基础信息」页复制 **App ID**（`cli_` 开头）和 **App Secret**，
   填入 `.env` 的 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`。
2. 获取你自己的 open_id（填 `FEISHU_OWNER_OPEN_ID`），任选一种：
   - 开放平台「API 调试台」→ 搜索「通过手机号或邮箱获取用户 ID」
     （`/contact/v3/users/batch_get_id`），输入你的企业邮箱得到 open_id；
   - 或搜索「获取用户信息」接口直接查询；
   - 程序运行后，你给机器人发一条消息，在服务日志里也能看到该 open_id。

## 6. 验证

1. 单聊给机器人发「请问年假怎么申请」，无经验时会在日报里生成草稿；
2. 等待次日 08:30（或手动 `python main.py daily`）收到日报卡片；
3. 卡片上点「批准/驳回」，或发送指令 `验证 #1`、`改 #1 新内容`、`停用 #1`。

## 常见报错

| 报错 | 原因与处理 |
|---|---|
| 230002 bot can not be outside the group | 机器人不在该群，先把机器人加进群 |
| 230006 Bot ability is not activated | 未启用机器人能力，回到第 1 步 |
| 230013 NO availability to this user | 应用可用范围没包含该用户，重新发布并调整可用范围 |
| 230027 Lack of necessary permissions | 权限未开通或版本未发布，检查第 2、4 步 |
| 长连接保存失败 | 程序未运行或网络不通，确认 `main.py` 已启动且能访问公网 |
