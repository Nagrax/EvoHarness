# 个人身份与组织员工

组织数字员工承担岗位，执行 Run 持有任务范围授权；个人数字分身使用个人知识与审批权。个人 OAuth token 不随岗位交接，也不由部署管理员代领。

同一飞书群可涉及多个业务空间；群 ID、飞书 tenant 和组织空间分别建模。发送动作按批准载荷与身份重验，回执未知时等待核对，不重试伪装成功。

实现入口：[身份校验](../feishu-daily-agent/app/services/identity.py)、[OAuth](../feishu-daily-agent/app/services/oauth.py)、[组织服务](../evoharness/organization/service.py)。
