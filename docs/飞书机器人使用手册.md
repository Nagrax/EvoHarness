# 飞书接入

飞书是 EvoHarness 的可选渠道，组织与工作状态由根产品服务维护。

1. 安装根依赖后，安装 `feishu-daily-agent/requirements.txt`。
2. 复制 `feishu-daily-agent/.env.example` 为该目录的 `.env`，填写自己的应用配置、消息范围、数据库与模型参数。默认先用测试/影子模式核对事件和草稿。
3. 在飞书开放平台配置应用权限、事件订阅与机器人身份。个人身份发送还需本人 OAuth 同意。
4. 在 `feishu-daily-agent` 目录运行 `python main.py --help` 查看运行与检查命令。

群聊交互默认由 @ 触发，回复显式 @ 对方。个人订阅、私聊和组织知识分别授权。自动发送仅在策略、白名单与有效批准均满足后启用；未收到真实回执的发送保留待核对状态。

配置与程序入口：[配置模板](../feishu-daily-agent/.env.example)、[渠道入口](../feishu-daily-agent/main.py)。
